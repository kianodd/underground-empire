# امپراتوری زیرزمینی (Underground Empire)

بازی مدیریتی، اقتصادی و استراتژیک تحت وب (PWA) با رابط فارسی و RTL. کاملاً سمت کاربر (Client-side) اجرا می‌شود و به سرور نیاز ندارد. همه محصولات، شخصیت‌ها و رویدادهای بازی کاملاً خیالی و انتزاعی‌اند.

## حلقه اصلی بازی

تولید محصولات خیالی ← ترکیب ویژگی‌های خیالی و ساخت محصول ویژه ← مذاکره و فروش به مشتریان ← مدیریت توجه پلیس (Heat) ← استخدام نمایندگان فروش ← باز کردن مناطق شهر ← پیشرفت در ۶ مرحله تا «امپراتور زیرزمینی».

## نسخه ۲ — فروشگاه مواد و ترکیب ترتیب‌محور

- **فروشگاه:** ۵۳ مادهٔ معمولی (میوه، عسل، قهوه، خشکبار، ادویه، تازه‌ها…) با قیمت روزانهٔ نوسانی (±۲۰٪) و موجودی روزانه. خرید با تعداد ۱/۵/۱۰/حداکثر و فروش برگشتی با نصف قیمت.
- **انبار مواد:** مواد خریده‌شده در انبار نگه‌داری می‌شوند (ظرفیت مشترک با محصولات). بسته شروع: ۲ موز + ۲ عسل.
- **ترکیب ترتیب‌محور:** ۱ محصول پایه + ۱ تا ۴ ماده در خانه‌های مرتب. وزن خانه‌ها: ۱۰۰٪، ۶۰٪، ۳۵٪، ۲۰٪. مادهٔ اول ویژگی اصلی و نام محصول را می‌سازد و مادهٔ آخر روی ماندگاری/محبوبیت اثر اضافه دارد.
- **۱۴۰ قانون هم‌افزایی/ناسازگاری** (جفت‌های مرتب + قانون‌های دسته‌ای)؛ «موز ← عسل» با «عسل ← موز» نتیجهٔ متفاوتی می‌دهد. همهٔ ترکیب‌های مرتب به‌صورت قطعی و رویه‌ای محاسبه می‌شوند (بی‌نهایت ترکیب ممکن).
- **پیش‌نمایش زنده** با چیپ‌های ویژگی (+سبز/−قرمز) و ارزش تقریبی؛ هم‌افزایی‌های ناشناخته تا اولین ساخت پنهان می‌مانند.
- **دفتر کشف‌ها:** هر ترکیب مرتبِ تازه «کشف» می‌شود و پاداش (۵۰ سکه + ۳ اعتبار) می‌دهد.
- مشتری‌ها یک ویژگی بازیِ موردعلاقه دارند؛ محصول ویژه‌ای که آن ویژگی را داشته باشد قیمت قابل‌قبول بالاتری در مذاکره می‌گیرد.
- همهٔ ویژگی‌ها (قدرت، تمرکز، سرعت، آرامش، محبوبیت، ماندگاری، درخشش، کیفیت) صرفاً عددهای خیالیِ داخل بازی‌اند.
- ذخیره‌های نسخه ۱ به‌صورت خودکار به نسخه ۲ مهاجرت می‌کنند (بدون از دست رفتن پیشرفت).

## نسخه ۴ — ترکیب رایگانِ زمان‌دار + بالانس اقتصاد + رابط ساده‌تر

- **ترکیب رایگان، ولی زمان‌دار:** ساخت محصول ویژه هیچ سکه‌ای نمی‌خواهد؛ مواد در لحظه شروع مصرف می‌شوند و ساخت در «صف ساخت» (حداکثر ۵ کار، به‌ترتیب) انجام می‌شود. زمان ساخت = ۱ + تعداد مواد (۱ ماده = ۲ ساعت بازی، ۴ ماده = ۵ ساعت). لغو ساخت، مواد را کامل برمی‌گرداند. پاداش کشف هنگام آماده‌شدن داده می‌شود. پیشرفت آفلاین تا سقف ۸ ساعت بازی صف را جلو می‌برد.
- **بالانس اقتصاد:** هزینه تولید ≈ ۵۰٪ قیمت بازار؛ قیمت مواد ۵ تا ۶۵ سکه با نوسان روزانه ±۲۵٪؛ ارزش ترکیب حداکثر ۳ برابر هزینه ورودی؛ قیمت بالای ۱۲۰٪ بازار سفارش‌ها را به‌شدت کم می‌کند؛ اجاره روزانه ۵۰ تا ۴۰۰ سکه؛ هزینه بازکردن مناطق ۱٬۵۰۰ تا ۴۰٬۰۰۰؛ هزینه ارتقاها ×۲٫۲ در هر سطح. شبیه‌سازی ۳۰ روزه در تست‌ها بررسی می‌کند که ثروتمندشدن سریع اتفاق نیفتد ولی بازی سودده بماند.
- **رابط ساده‌تر:** متن‌های توضیحی کوتاه شدند، راهنمای شروع داشبورد ۴ قدم کوتاه و قابل بستن است، و جزئیات ترکیب زیر «جزئیات» پنهان شده است.

## اجرای محلی

```bash
npm install
npm run dev
```

تست منطق بازی:

```bash
npm test
```

ساخت نسخه نهایی:

```bash
npm run build
```

## انتشار روی GitHub Pages

1. مخزن را روی GitHub بساز و سورس را push کن.
2. در تنظیمات مخزن، Pages را روی حالت «GitHub Actions» بگذار.
3. فایل `.github/workflows/deploy.yml` با هر push روی شاخه `main` به‌صورت خودکار build و deploy می‌کند.
4. مسیر پایه (base) در `vite.config.ts` برابر `/underground-empire/` است؛ اگر نام مخزن عوض شد، آن را هم تغییر بده.

## ذخیره‌سازی و PWA

- ذخیره خودکار در IndexedDB (همراه با Export/Import فایل JSON و بازنشانی کامل).
- قابل نصب روی موبایل و دسکتاپ (Add to Home Screen) و قابل بازی آفلاین پس از اولین بارگذاری.
